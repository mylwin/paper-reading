## 对技能的实质调整

[ICML独立风格档案](../.claude/skills/paper-writing-shared/venues/icml.md)已更新为50篇完成状态，继续分别列出官方要求、语料观察和编辑建议。两技能保留写作／润色分工，共用资源无需全局 Nature 路径。

| 检查所得 | 对应行为 |
|---|---|
| 纯理论稿可完全由定理与证明提供证据（eecff206、cb55acae、bece118e、faa9d83f） | 不强制补实验、消融或经验性能段落 |
| 实证分析也能以理解现象为贡献（72cb7861） | 不制造新算法或理论保证 |
| 核心证明可以在正文（faa9d83f） | 不一律把完整论证移走；正文保留判断贡献所需内容 |
| 探索性证据需要相应语气（f7c67196、bece118e） | 不设 may、suggest、promise 等禁词表 |
| 问答、临床研究说明等有明确语境（59310425、c8be7b24） | 按读者需要使用，不扩成每篇固定自辩栏目 |
| 个别论文主张、表格或公式存在查询项 | 查询保存在研究记录；不移植为新稿逐段免责声明 |

共同原则现在同时处理夸大和过度保守：有证据的结果直接陈述；重要条件在影响含义的位置说明；准确有力的原句可以不改；不要求每条主张列出所有未验证情况。只有与作者材料直接相关的事实缺口进入作者待办。

## 写作与润色实际练习

[12个情境的输出及人工核对](2026-10-28-ICML技能有效性验证_证据/behavioral/outputs-and-review.md)，每个同名JSON保存请求、给定事实、原稿、实际输出、作者待办和核对理由；[执行清单](2026-10-28-ICML技能有效性验证_证据/behavioral/evaluation-manifest.json)保存规则版本。

| 用例 | 实际核对结果 |
|---|---|
| 01 实证起草 | 摘要、引言、结果及局限能直接识别内存收益和耗时交换；无虚构实验或引用 |
| 02 纯理论起草 | 保留光滑性、无偏性、方差条件、min/期望/平方梯度及常数依赖；不把平稳性写成到全局最优点距离 |
| 03 探索性起草 | 观测直接表述，解释保留 suggest/promising 与小范围证据相配 |
| 04 过度保守润色 | 删除 may perhaps/could potentially 连环弱化，保留一次比较范围 |
| 05 过强主张润色 | 撤去 universal/SOTA/加速，仍明确报告25%状态内存下降和5%时间增加 |
| 06 准确原句 | 原样保留，未为了“润色”添加不必要限定 |
| 07 机制假说 | 观测与可能解释分开，未把相关性变成因果证明 |
| 08 数字冲突 | 未静默选择20.09或17.09；暂交方向性文字，具体数字待作者确认，不能称数字定稿完成 |
| 09 中文转英文 | 100→80小时正确写为降低20%；不生成没有提供的显存结果 |
| 10 理论压缩 | 保留固定参数开区间、复杂度指数及smoothed对象，删除重复条件 |
| 11 分析型贡献 | 无新算法也能明确陈述贡献，重要反例在结果旁说明 |
| 12 局部背景润色 | 按句子范围完成，不追问整篇实验、不强制选venue或生成工程 |

这些是本次主代理加载技能后完成的人工情境练习，生成者与核对者相同；没有另起独立模型、旧规则对照、重复采样或统计质量估计。它们验证具体操作路径及已知问题的处理，尚不能证明对真实长稿或不同模型普遍有效。没有用弱词计数代替语义判断。

## LaTeX 工程、实际发现及修复

基于已打包的官方 ICML2026 样式建立三个新的多文件工程：投稿原稿、投稿润色稿和独立终稿迁移目录。全部使用本地 latexmk/pdflatex，未修改官方样式。文件与数值均为明确标记的合成测试材料，不是新增研究发现。

- 三个工程均编译成功、静态检查无issue。投稿润色与终稿迁移的两次新比较均未发现宏定义、数学表达、数字、引用／标签键或文献源变化；人工复核了条件和结论含义。见[编译与检查证据目录](2026-10-28-ICML技能有效性验证_证据/latex/fixture-manifest.json)。
- 投稿润色版与终稿各3页，逐页查看全部6页：标题、摘要、公式、算法、单栏图、跨栏表、参考文献、定理及附录均可读。主文含浮动图表实际为2页。投稿版显示匿名作者，抽取文本和pdfinfo字段无示例实名；终稿显示示例作者并有对应PDF作者字段。见[视觉及语义核对](2026-10-28-ICML技能有效性验证_证据/latex/visual-and-semantic-review.json)。
- 首次渲染曾出现算法浮在摘要上方、跨栏表独占延后页，且主文结束label漏算浮动页。[首次问题记录](2026-10-28-ICML技能有效性验证_证据/latex/initial-visual-findings.json)保留失败证据。随后用普通浮动位置选项及共同的给定事实说明修复测试布局，再编译与全页查看。排版压力用例的说明性文字不计作写作简洁性证据。
- 该发现已写入共享LaTeX规则：主文label是辅助，必须检查延后排出的正文图表实际页码。`project.py`未改，静态计数本身仍不保证捕捉所有浮动页。
