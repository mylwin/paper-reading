# 研究领域调研

`07-research/` 用于集中保存研究领域、技术方向、方法体系和相关工具生态的专题调研工作。

这里的内容可以综合多篇论文、官方文档、项目资料、行业信息和个人分析，适合用于梳理研究脉络、比较技术方案、记录领域进展，以及为后续论文阅读或研究选题提供参考。它与按单篇论文组织的原文、解析、笔记、公式解读和翻译资料相互独立，但可以通过相对路径进行关联。

## 命名规范

调研文件使用以下格式命名：

```text
07-research/
├── README.md
└── YYYY-MM-DD-<调研主题>.<扩展名>
```

例如：

```text
2026-09-15-大模型训练主流框架调研_2021-2026.md
```

其中日期使用年月日格式，表示调研创建或主要更新日期；主题名称应简洁明确，能够体现调研范围。若某项调研包含较多图片、附件或多个文件，可建立与调研主题同名的子目录进行管理。

**本目录不使用 `YYYY-MM/` 月份分层**，文件名带日期是本目录与 `08-daily/<日期>/` 的既定规范（论文资料目录的文件名不带日期）。引用论文资料时使用相对本文件的路径，例如 `../01-raw/2026-09/<论文标题>.pdf`。
