# 术语与符号

| 术语/符号 | 含义 |
|---|---|
| Confidence Gate | 用户指定方法名 |
| fixed classifier | 分类器固定；具体模型未知 |
| x, K, p_k(x) | 输入、类别数、分类器报告的类别概率 |
| y-hat(x) | 分类器原有预测，不新增 tie-break 假设 |
| s(x), a(x), g(x), bottom | 最大概率、接受指示、门控输出、拒绝符号 |
| C-hat, R-hat | 仅拟议的接受频率与接受错误率定义 |
