# 论文阅读笔记

`03-notes/` 用于保存针对单篇论文的精读笔记、阅读思考、问题记录和复现实验材料。

## 目录规则

```text
03-notes/
└── <论文标题>/
    ├── 精读.md
    ├── <其他笔记主题>.md
    └── images/
```

- 每篇论文建立一个与论文标题一致的目录。
- `精读.md` 是 AI 生成精读内容的固定入口；其他文件使用能够反映内容的语义化名称。
- 本篇论文图片放在对应目录的 `images/` 下；引用文献图片放在 `images/<被引用论文标题>/` 下。
- 图片和跨目录引用使用指向真实文件的相对路径，不使用符号链接。
