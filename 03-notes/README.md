# 论文阅读笔记

`03-notes/` 用于保存针对单篇论文的精读笔记、阅读思考、问题记录和复现实验材料。

## 目录规则

```text
03-notes/
├── README.md
├── index.md
└── YYYY-MM/
    ├── README.md
    └── <论文标题>/
        ├── 精读.md
        ├── <其他笔记主题>.md
        └── images/
```

- 月份为该论文的**入库月份**，与 `01-raw/YYYY-MM/`、`02-markdown/YYYY-MM/` 保持一致。
- 每篇论文建立一个与论文标题一致的目录；`精读.md` 是 AI 精读内容的固定唯一入口（`paper-analyze` skill 默认写入该文件）。
- 其他文件使用能够反映内容的语义化名称；本篇论文图片放在对应目录的 `images/` 下，引用文献图片放在 `images/<被引用论文标题>/` 下。
- 图片和跨目录引用使用**相对本文件**的真实路径（本目录内文件引用工作区根目录下的资料需要 `../../../`），不使用符号链接。
- 尚未精读的论文不预建目录，在月份 `README.md` 与 `index.md` 中登记为 `未精读`；进行中登记 `精读中` + 开始日期。

## 说明文件

- `index.md`：精读总索引，含状态、开始与完成日期、优先级与精读文件路径。
- `YYYY-MM/README.md`：该月论文的精读清单与未精读提醒。

## 日期与状态的来源

- `精读状态`、`精读文件` 由脚本按磁盘是否存在 `精读.md` 推导。
- `精读开始`：git 首次提交日期 → `精读.md` frontmatter 的 `date` → 文件时间。
- `精读完成`：已精读时取 `精读.md` frontmatter 的 `date`；要修正完成日期，请改笔记 frontmatter 的 `date` 后重新运行脚本。
- `优先级`、`精读中` 以及脚本推不出的日期会**保留上一版表格中人工填写的值**，不会被脚本清空。
