### 1. Beyond Low-Rank Parameterization: Narrowing the Gap Between LoRA and Full Fine-Tuning via Gradient Decomposition — 研究优先级 3.20

- **来源**：arxiv
- **主题（大方向）**：大模型优化器设计
- **细分领域**：自适应与状态内存
- **题目中文翻译**：超越低秩参数化：通过梯度分解缩小 LoRA 与全量微调之间的差距
- **作者**：Yihao Ouyang, Shiwei Li, Haozhao Wang, Xiandi Luo, Zhuoqi Hu, Jinglun Yu, Yichen Li, Ruixuan Li
- **英文摘要**：Low-Rank Adaptation (LoRA) is a widely used approach to parameter-efficient fine-tuning (PEFT), yet a performance gap can remain relative to full fine-tuning (FFT). Many LoRA variants improve the initialization or optimization of low-rank factors. At each training step, however, their first-order weight-space directions are constrained by the current parameterization. We characterize the corresponding LoRA-accessible gradient space and show that it coincides with the tangent space induced by the current LoRA parameterization. This characterization yields an orthogonal decomposition of the full weight gradient at the current model parameters. We term the component orthogonal to this space the normal gradient. Based on this decomposition, we propose GDLoRA (Gradient-Decomposed Low-Rank Adaptation). GDLoRA reconstructs the full weight gradient from forward activations and backward signals, extracts its normal component, and directly updates the base weights with this component, while retaining standard AdamW optimization for the LoRA factors. GDLoRA incorporates complementary normal gradients without increasing standard LoRA's optimizer-state memory budget under matched adapter and optimizer configurations. Experiments on natural language understanding, mathematical reasoning, commonsense reasoning, and image classification show that GDLoRA consistently improves over LoRA and narrows the performance gap to FFT. The code is available at https://anonymous.4open.science/r/GDLoRA.
- **中文摘要**：低秩适应（LoRA）是一种广泛使用的参数高效微调（PEFT）方法，但相对于全量微调（FFT），其表现仍可能存在差距。许多 LoRA 变体改进了低秩因子的初始化或优化。然而，在每个训练步骤中，它们在权重空间中的一阶方向受到当前参数化的约束。我们刻画了对应的 LoRA 可达梯度空间，并表明它与当前 LoRA 参数化诱导的切空间一致。这一刻画给出了当前模型参数处完整权重梯度的正交分解。我们把与该空间正交的分量称为法向梯度。基于这一分解，我们提出 GDLoRA（梯度分解低秩适应）。GDLoRA 从前向激活和反向信号中重建完整权重梯度，提取其法向分量，并用该分量直接更新基础权重，同时保留对 LoRA 因子的标准 AdamW 优化。在适配器和优化器配置匹配的条件下，GDLoRA 引入互补的法向梯度，而不增加标准 LoRA 的优化器状态内存预算。在自然语言理解、数学推理、常识推理和图像分类上的实验表明，GDLoRA 一致优于 LoRA，并缩小了与 FFT 的表现差距。代码见 https://anonymous.4open.science/r/GDLoRA。
- **一句话总结**：GDLoRA 将完整梯度分为切向与法向分量，在保留适配器 AdamW 的同时直接更新基础权重的法向分量。
- **摘要声称的核心贡献**：
  - GDLoRA 将完整梯度分为切向与法向分量，在保留适配器 AdamW 的同时直接更新基础权重的法向分量。
- **方法思路**：利用前向激活与反向信号重建完整梯度，投影到 LoRA 切空间的正交补，再直接更新基础权重。
- **摘要报告的主要结果**：摘要报告四类任务上优于 LoRA、缩小 FFT 差距，但没有量化收益或峰值显存数字；状态内存不增加不等于总训练内存不增加。
- **选择理由**：直接命中子空间几何和优化器状态内存；可检验绕过参数化约束是否比仅改适配器初始化更有效。
- **证据边界与待核验**：初步判断，待全文核验；依据官方题目与原始摘要。需核验完整梯度重建的激活/临时梯度开销、基础权重更新后的保存与部署方式、匹配预算及近邻基线；不能把优化器状态内存等同峰值显存。
- **阅读决策**：精读

### 2. Gradient Conflict in Multimodal Pretraining — 研究优先级 3.00

- **来源**：openreview
- **主题（大方向）**：大模型优化器设计
- **细分领域**：自适应与状态内存
- **题目中文翻译**：多模态预训练中的梯度冲突
- **作者**：Sreya Roy Chowdhury, Sofiia Kononovych, Ge Shan, Sahar Rajabi, Sirisha Rambhatla
- **英文摘要**：Early-fusion multimodal models train text and image tokens through a single set of weights, so both

modalities compete for every parameter update. Low-rank optimizers reduce optimizer memory by

confining that update to a small subspace of the gradient, but they are validated almost exclusively

on text-only training, where only one token distribution is present. We ask whether this restriction

aggravates conflict between modality gradients. Pretraining a 400M-parameter Chameleon model

on interleaved image-text documents, we measure the angle and the relative magnitude of the text

and image gradients throughout training under full-rank AdamW, under a subspace built by sin-

gular value decomposition (SVD), and under a control in which the subspace is drawn at random.

Conflict is confined to the first few hundred steps and clears in every case, though the low-rank runs

pass through a sharper and longer transient than full-rank AdamW before doing so. The relative

magnitudes differ: the SVD yields a larger share for image gradients than either full-rank training

or a random subspace of the same size, while random projection matches full-rank training. Beyond

the transient, restricting the optimizer to a subspace leaves the conflict pattern unchanged and cuts

optimizer memory substantially, with both low-rank runs ending 0.17–0.30 higher in validation

loss than AdamW at its own tuned learning rate.
- **中文摘要**：早期融合多模态模型通过同一组权重训练文本和图像 token，因此两种模态会在每次参数更新中相互竞争。低秩优化器通过把更新限制在梯度的一个小子空间内来减少优化器内存，但其验证几乎完全局限于只有一种 token 分布的纯文本训练。我们考察这种限制是否会加剧模态梯度之间的冲突。我们在交错排列的图文文档上预训练一个 400M 参数的 Chameleon 模型，并在整个训练过程中测量文本与图像梯度的夹角及相对大小，比较完整秩 AdamW、通过奇异值分解（SVD）构造的子空间，以及随机抽取子空间的对照。冲突仅发生在最初几百步，并且在所有情形下都会消退，不过低秩训练在消退前经历的暂态比完整秩 AdamW 更剧烈、持续更久。相对大小则有所不同：SVD 分配给图像梯度的份额高于完整秩训练或相同大小的随机子空间，而随机投影与完整秩训练相当。暂态之后，将优化器限制在子空间内不会改变冲突模式，并显著减少优化器内存；两种低秩训练最终的验证损失都比采用其自身调优学习率的 AdamW 高 0.17–0.30。
- **一句话总结**：低秩子空间使多模态梯度冲突暂态更剧烈、更长，但长期冲突模式不变，且验证损失高于调优 AdamW。
- **摘要声称的核心贡献**：
  - 低秩子空间使多模态梯度冲突暂态更剧烈、更长，但长期冲突模式不变，且验证损失高于调优 AdamW。
- **方法思路**：在 400M Chameleon 图文预训练中，对照完整秩 AdamW、SVD 子空间和同尺寸随机子空间，测量梯度角度与相对大小。
- **摘要报告的主要结果**：摘要报告冲突集中于最初几百步；SVD 更偏向图像梯度，两种低秩训练最终验证损失均高 0.17–0.30。
- **选择理由**：为低秩更新的低内存收益提供负面效果对照，可与第一篇比较子空间约束究竟遗漏了哪些梯度信息。
- **证据边界与待核验**：初步判断，待全文核验；依据官方题目与原始摘要。OpenReview PDF 返回 HTTP 403，仅可用官方搜索 API 摘要。需查子空间秩、刷新频率、种子、损失聚合、各方法学习率调参公平性和峰值内存；0.17–0.30 不能泛化到所有多模态模型。
- **阅读决策**：精读

### 3. Speedrunning Relational Foundation Model Pretraining — 研究优先级 3.47

- **来源**：arxiv
- **主题（大方向）**：大模型优化器设计
- **细分领域**：符号与范数几何优化
- **题目中文翻译**：关系型基础模型预训练速跑
- **作者**：Gabriel Wedson Mendonça de Souza Veloso, Luan Borges Teodoro Reis Sena, Denis Oliveira Correa, Francisco Galuppo Azevedo
- **英文摘要**：Progress on foundation model pretraining is gated by who can afford a trial, and relational pretraining is no exception. Recipes are developed inside individual labs, reported under private protocols, and do not accumulate. Speedrun leaderboards remove that barrier by decentralizing the search rather than the training run. The problem is fixed, the stack is open, entries are ranked by wall-clock time to a quality target, and one GPU is enough to hold the record. We introduce modded-nanoRT, the first such leaderboard for Relational Transformers. Which database to hold out decides whether the benchmark can resolve improvements at all, so we fix it by calibration, ranking six candidates by how sharply a 45-minute learning curve separates improvement from seed noise. We open the leaderboard with typed trilinear attention, a relational operator that conditions attention scores and values on the foreign key traversed, together with Muon and SIGReg. The recipe reaches the target in 305.63 seconds on one NVIDIA H200, 8.11x faster than the reference implementation, and wins 13 of 15 pairs outside the development database. We will release the benchmark, its frozen artifacts, and the record runs. Our code is available at https://github.com/kunumi/nanoRT.
- **中文摘要**：基础模型预训练的进展受制于谁能负担一次试验，关系型预训练也不例外。训练配方在各个实验室内部开发，按私有协议报告，因而无法累积。速跑排行榜通过分散搜索过程而非单次训练运行来消除这一障碍。问题被固定下来，技术栈开放，提交项按照达到质量目标所需的墙钟时间排名，而一块 GPU 就足以保持纪录。我们推出 modded-nanoRT，这是首个面向 Relational Transformers 的此类排行榜。选择留出哪一个数据库，决定了基准究竟能否分辨性能改进；因此我们通过校准将其固定：按照一条 45 分钟学习曲线区分改进与随机种子噪声的清晰程度，对六个候选数据库排序。我们以带类型的三线性注意力作为排行榜的初始方案：这一关系算子根据所遍历的外键来条件化注意力分数和值，并结合 Muon 和 SIGReg。该配方在一块 NVIDIA H200 上用 305.63 秒达到目标，比参考实现快 8.11 倍，并在开发数据库之外的 15 对比较中赢得 13 对。我们将发布该基准、其冻结产物以及创纪录的运行记录。代码见 https://github.com/kunumi/nanoRT。
- **一句话总结**：modded-nanoRT 将预训练比较固定为单 GPU 达到质量目标的墙钟时间；Muon 与架构、SIGReg 共同构成加速配方。
- **摘要声称的核心贡献**：
  - modded-nanoRT 将预训练比较固定为单 GPU 达到质量目标的墙钟时间；Muon 与架构、SIGReg 共同构成加速配方。
- **方法思路**：以学习曲线校准留出数据库，冻结质量目标和栈，用 typed trilinear attention、Muon、SIGReg 的组合开榜。
- **摘要报告的主要结果**：摘要报告单 H200 上 305.63 秒、相对参考实现 8.11 倍、开发数据库外 13/15 成对比较获胜；这些是组合配方结果。
- **选择理由**：条件性选读：可借鉴优化器比较的时间预算、目标校准和随机种子控制；核心贡献是关系模型评测协议，不是新的 Muon 算法。
