# 公式解读

`04-equation_problem/` 用于保存论文中的公式解读、推导过程、公式伴读和相关附件。

## 目录规则

```text
04-equation_problem/
├── README.md
└── <论文标题>/
    ├── <公式解读或推导>.md
    └── <图片或其他附件>
```

- **本目录不按月份分层**（只有 `01-raw`、`02-markdown`、`03-notes`、`06-translation` 使用 `YYYY-MM/`），只按论文标题建立目录。
- 每篇论文建立一个与论文标题一致的目录；尚未精读时允许先建立空目录占位。
- 同一篇论文的公式材料统一放在该论文目录下，可按内容需要组织文件和子目录。
- 可通过相对路径链接到 `02-markdown/YYYY-MM/`、`03-notes/YYYY-MM/` 中的相关内容，不复制整篇论文。本目录下的文件位于工作区根目录下的第二层，引用其他资料需使用 `../../`：

```markdown
[论文 Markdown](../../02-markdown/2026-09/<论文标题>.md)
[精读笔记](../../03-notes/2026-09/<论文标题>/精读.md)
[原始 PDF](../../01-raw/2026-09/<论文标题>.pdf)
```
