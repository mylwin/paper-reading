# 公式解读（定稿）

`04-equation_problem/` 保存论文公式的**定稿**解读：可独立阅读的完整推导、逐公式伴读讲解、附录级推导细节，以及用户自己的公式材料与附件。

**这里不放过程稿。** 逐单元问答记录、全局推理的中间草稿属于 `08-reading/<论文标题>/`。判断标准只有一条：去掉问答上下文后还能独立读懂的，才进本目录。

## 目录规则

```text
04-equation_problem/
├── README.md
└── <论文标题>/
    ├── 全局推理.md          # AI 定稿：完整推导手稿
    ├── 公式伴读.md          # AI 定稿：逐公式伴读讲解
    ├── 附录完整推导.md      # AI 定稿：附录级细节推导
    ├── 你的疑问.md          # 用户手写：哪里没懂
    └── <扫描图片、附件或其他公式材料>
```

- **本目录不按月份分层**（只有 `01-raw`、`02-markdown`、`03-notes`、`06-translation` 使用 `YYYY-MM/`），只按论文标题建立目录。
- 每篇论文建立一个与论文标题一致的目录；尚未精读时允许先建立空目录占位。
- `全局推理.md`、`公式伴读.md`、`附录完整推导.md` 是 `paper-sgd-reading` 产出的固定定稿名，按内容需要只存在一部分即可，不要求三件齐全，也不要改写这些名字。
- 除固定定稿名之外，不按单条公式强制拆分文件，也不限制该论文目录内的其他文件名、格式或子目录结构。
- **所有权区分**：三个固定定稿名文件由 AI 撰写；用户自己的理解、推导与疑问（如 `你的疑问.md`）使用其他文件名，AI 只读取作为讲解重点，不覆盖、不重写。
- 同一篇论文的公式材料统一放在该论文目录下，不要散落在 `04-equation_problem/` 根目录或其他论文目录。
- 可通过相对路径链接到 `02-markdown/YYYY-MM/`、`03-notes/YYYY-MM/` 中的相关内容，不复制整篇论文。本目录下的文件位于工作区根目录下的第二层，引用其他资料需使用 `../../`：

```markdown
[论文 Markdown](../../02-markdown/2026-09/<论文标题>.md)
[精读笔记](../../03-notes/2026-09/<论文标题>/精读.md)
[原始 PDF](../../01-raw/2026-09/<论文标题>.pdf)
[配套过程稿](../../08-reading/<论文标题>/<论文标题>_精读笔记.md)
```

## 与 08-reading 的分界

| 内容 | 落点 | 谁能读 |
| --- | --- | --- |
| 完整推导定稿、伴读定稿、附录推导 | `04-equation_problem/<论文标题>/` | 当作教材使用 |
| 用户手写的疑问与自己的推导 | `04-equation_problem/<论文标题>/` | AI 只读，作为讲解输入 |
| 逐单元问答记录、全局推理草稿 | `08-reading/<论文标题>/` | `paper-weekly` 用来判断卡点 |

完整规范见工作区 `.AGENT.md`。
