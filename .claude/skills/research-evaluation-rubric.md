# 研究人员论文评价准则

本准则供 `paper-analyze`、`paper-daily`、`paper-conf`、`paper-weekly` 与
`paper-sgd-reading` 共用。目标不是模拟大众推荐榜，而是帮助博士生、博士后和高校研究人员
做选题判断、文献定位、方法审计和下一步研究决策。

## 一、先区分两种分数

### 1. 检索预筛分

只使用标题、摘要、日期、来源和引用元数据时，分数只能叫：

- **研究优先级**：这篇论文是否值得进入候选阅读队列。
- **摘要证据充分度**：摘要是否清楚报告问题、方法、比较和结果。
- **影响力信号**：引用或高影响力引用提供的滞后信号。

它们都**不是论文质量分**。不得从 `novel`、`SOTA`、`first` 等自我宣传词推断创新性，
不得把引用量直接解释为正确性或学术质量。引用受论文年龄、领域规模、作者网络、会议曝光和
工具流行度影响；新论文没有引用也不是负面证据。

### 2. 全文研究评价

只有读过方法、主要定理或实验、局限性和关键相关工作后，才能做全文评价。每个判断必须附：

1. **证据位置**：章节、定理、表格、图或附录。
2. **判断理由**：证据为何支持该分数。
3. **不确定性**：缺了什么信息，补读什么可以改变判断。
4. **置信度**：高 / 中 / 低。

摘要只能支持低置信度初评。若只拿到摘要，输出“待全文核验”，不要补全实验或证明细节。

## 二、证据优先级

从高到低使用：

1. 正文、附录、补充材料、公开代码与原始实验记录。
2. 论文中的定理、证明、表格、消融、误差条和失败案例。
3. 作者在摘要和正文中的主张。
4. 元数据、引用数、机构或发表场所。

发表场所、作者声望和引用量只能作为背景，不能替代对论证的审查。始终区分：

- **作者主张**：论文说自己做到了什么。
- **论文证据**：文中实际证明或实验支持了什么。
- **评审推断**：基于证据还能合理推出什么。
- **尚未证实**：证据不够，或存在竞争性解释。

## 三、先判论文类型

在评分前标注主要类型，可多选：

- 理论 / 理论算法
- 实证方法 / 模型
- 系统 / 工程
- 数据集 / 基准
- 综述 / 观点
- 混合型

不同类型使用不同证据标准。理论论文不因没有大规模实验自动扣分；系统论文不能仅凭一个漂亮
定理替代端到端评测；混合型论文声称了几类贡献，就分别审查几类证据。

## 四、全文评价维度（1-5 分，允许 N/A）

分数使用整数或 0.5 分，避免无证据的伪精确。任何 N/A 维度从加权分母中移除，不按 0 分处理。

| 维度 | 研究人员要问的问题 |
|---|---|
| 问题重要性与界定 | 问题是否真实、重要且边界清楚？评价对象、约束和成功条件是否可识别？ |
| 原创性与净增量 | 相对最接近的 2-5 篇工作，新增的是问题、假设、方法、定理、证据还是系统能力？能否剥离成独立贡献？ |
| 技术正确性与严谨性 | 推导、算法、因果链和实现是否自洽？关键假设是否必要、可验证、非空泛？是否有证明缺口或信息泄漏？ |
| 证据强度与替代解释 | 证据是否真正检验核心主张？基线、对照、统计不确定性、消融和失败案例能否排除更简单解释？ |
| 可复现性与透明度 | 代码、数据、超参、算力、随机种子、证明细节和评测协议是否足以复核？ |
| 外推边界与稳健性 | 结论在哪些数据、规模、假设、硬件和预算下成立？边界条件、负面结果和失效模式是否明确？ |
| 研究生成力 | 是否带来新问题、可复用工具、统一视角、可检验猜想，或能改变后续研究设计？ |
| 当前课题契合度 | 对用户当前研究问题的直接性、信息增益、迁移成本、验证成本和时间敏感性如何？ |

### 统一分数锚点

- **5**：证据充分的领域级贡献，明显改变问题理解或方法边界；最强近邻也难以解释其净增量。
- **4**：强而可信的贡献，定位清楚、证据扎实，存在有限但不致命的边界。
- **3**：合格且有用的增量工作，核心主张基本成立，但贡献范围或证据覆盖有限。
- **2**：有潜在想法，但定位、正确性或验证存在实质缺口，当前不足以支撑主要主张。
- **1**：核心主张与证据明显不匹配，或存在严重方法错误。

不要默认给 7-8/10 式“礼貌分”。证据不足时降低置信度，而不是凭印象填高分。

## 五、分类型审查

### 理论 / 理论算法论文

重点检查：

- 定理相对已知结果究竟放宽了哪条假设、改善了哪个阶、覆盖了哪个新区域。
- 收敛率是否只在常数或记号上变化，是否存在隐藏维度、条件数或批量依赖。
- 假设是否可同时满足，结论是否非空泛，参数选择是否需要未知量。
- 上界是否有下界或反例支撑其紧性；有限样本结论与渐近结论是否混淆。
- 证明最关键的一步是什么，是否从引用文献无缝搬用，符号或条件是否发生变化。
- 算法是否可实现，oracle、内存、通信和调参代价是否被忽略。

### 实证方法 / 模型论文

重点检查：

- 数据划分、污染、泄漏和任务定义是否可靠。
- 是否与最强且公平的基线比较，训练预算、数据、调参和模型规模是否可比。
- 是否报告多随机种子、方差、置信区间或显著性；提升是否超过测量噪声。
- 消融是否能识别真正有效的组件；是否存在只挑有利数据集或指标的风险。
- 规模、分布外、鲁棒性和失败案例是否覆盖核心主张。

### 系统 / 工程论文

重点检查：

- 是否测量端到端瓶颈，而不是孤立微基准。
- 硬件、软件栈、并行策略和成本核算是否透明。
- 吞吐、时延、显存、能耗、精度和开发复杂度之间的权衡是否公平。
- 是否跨规模、负载和硬件验证，收益是否依赖难以迁移的特殊条件。

### 数据集 / 基准论文

重点检查：代表性、覆盖度、标注可靠性、污染、许可证、伦理风险、指标效度、是否会被捷径利用，
以及基准是否真的区分研究能力而非资源规模。

### 综述 / 观点论文

重点检查：检索协议、覆盖边界、分类法是否有解释力、是否综合冲突证据、是否提出可证伪命题。
不得因没有新模型或新实验而自动判低分。

## 六、聚合与决策输出

### 学术价值分

默认按下列权重聚合前七个维度；按类型可调整，但必须在报告里说明：

| 维度 | 默认权重 |
|---|---:|
| 问题重要性与界定 | 15% |
| 原创性与净增量 | 20% |
| 技术正确性与严谨性 | 20% |
| 证据强度与替代解释 | 20% |
| 可复现性与透明度 | 10% |
| 外推边界与稳健性 | 5% |
| 研究生成力 | 10% |

将 1-5 的加权均值按 `学术价值分 = 2.5 × (加权均值 - 1)` 映射到 0-10，并四舍五入到 0.5 分。整体分数必须与维度分、实际权重、证据强度和置信度一起展示。

### 当前课题优先级

不要直接等同于学术价值。单独给出：

- **必读**：直接改变当前问题定义、方法选择或实验设计。
- **精读**：学术价值高，且对当前课题有明确可迁移内容。
- **选读**：有局部信息增益，可定点阅读相关章节。
- **跟踪**：证据尚弱或暂时不契合，但方向可能发展。
- **略读/跳过**：对当前课题边际信息增益低，并说明原因。

决策时考虑当前课题契合度、预期信息增益、阅读/复现成本和时间敏感性。高分论文不一定必读，
低引用的新论文也可能因直接命中研究缺口而优先。

## 七、标准研究输出

完整精读或周报至少包含：

1. **最强版本的一句话贡献**：不照抄摘要。
2. **主张-证据-限制矩阵**：每个主要主张对应证据、反证风险和置信度。
3. **最接近工作对照表**：共同问题、关键差异、公平性、净增量。
4. **评分表**：各维度分数、证据位置、理由、置信度。
5. **致命问题与非致命局限**：明确区分。
6. **复现/验证计划**：最小可行验证、所需资源、判定指标、停止条件。
7. **研究机会**：可证伪假设，而不是泛泛“未来可进一步研究”。
8. **阅读决策**：必读/精读/选读/跟踪/略读，并说明对当前研究的具体用途。

## 八、禁止事项

- 不按作者、机构、会议名气替代内容判断。
- 不用引用数给新论文判低质量，也不把高引用当作正确性证明。
- 不把摘要中的宣传词当创新证据。
- 不把“偏理论”“没有落地”本身当缺点；要按论文声称的贡献类型评价。
- 不把缺失信息脑补成已完成实验、已证明结论或已开源代码。
- 不把“有趣”“很有潜力”“实验充分”等空泛形容词当理由。
- 不强行给所有维度打分；不适用写 N/A，证据不足写待核验。
