# 来源与修改说明

本地两个入口参考 [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills) 中 `nature-writing`、`nature-polishing` 与共享规则的分工和事实纪律。审计对象为本地安装快照；不声称它与上游当前 HEAD 完全相同。上游采用 Apache-2.0，许可证副本保存在 `licenses/nature-skills-Apache-2.0.txt`。这些说明是重新编写的适配版本，未修改全局安装。

| 原规则 | 处理 | 本地实现与原因 |
|---|---|---|
| 作者提供的事实、主张、证据与边界先于表达 | 保留 | `core/evidence.md`，缺失内容标待补，不补造结果 |
| 结构先于语言，术语表贯穿全文 | 保留 | `core/writing.md`、`core/polishing.md` |
| 按任务、类型、章节、语言、目标加载片段 | 改写 | 加入 venue、年份、投稿阶段与模板规格；只读取所需资源 |
| 面向宽领域读者的 Nature 叙事与发现链 | 改写 | 各 venue 档案分别规定读者与证据呈现，不推广为计算机论文的统一写法 |
| Nature summary paragraph、固定宽受众开头 | 移除默认 | 采用目标 venue 的摘要限制和稿件本身的信息需求 |
| 独立 Results/Discussion 与 Nature SI 分工 | 改写 | 允许方法/理论/实验组合；核心假设和改变结论的边界留正文，证明位置按 venue 指南 |
| 一个段落恰好一个固定功能 | 放宽 | 保持中心功能清楚；允许定义衔接、对照和必要限制，不机械拆段 |
| 默认禁止破折号等标点偏好 | 移除硬约束 | 只修复歧义和可读性问题，尊重现稿与目标模板 |
| 初次投稿行政材料、模拟审稿、rebuttal、绘图路由 | 移出范围 | 第一版聚焦正文与排版，只保留写作/润色两个技能 |
| 润色保护已有科学论证 | 保留并扩展 | 保护自定义命令、引用键、标签、公式、工程结构；实质性改动单独解释 |
| LaTeX 布局诊断与实际渲染 | 保留并收紧 | 不使用字号/间距/页边距修改规避会议限制，原官方文件按校验值维护 |

官方模板的所有权与许可各自独立，不由本项目重新授权。原 `.cls`、`.sty`、`.bst` 文件及模板内许可声明原样保留；有单独 LICENSE 的包随包保留。生成的正文骨架为本次原创；引用数据库中的指南条目仅演示参考文献排版，不代表研究文献。

风格档案中的规则必须区分官方要求、语料观察、编辑建议。没有逐篇完整阅读证据的规则只作为暂定建议，不能因下载或解析计数达标而升级为语料结论。完整调研记录保存在工作区 `07-research/2026-10-10-顶会顶刊写作风格调研_证据/`；技能正文与模板无需访问该工作区的绝对路径即可使用。
