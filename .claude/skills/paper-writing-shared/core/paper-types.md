# 论文类型对证据与结构的影响

## 理论

在结果前给出必要定义、问题与假设。说明定理改进的是误差率、样本复杂度、计算复杂度、适用范围还是假设强弱；核对比较条件。主文保留证明思想及关键障碍，附录提供完整推导。不强迫理论稿添加benchmark或消融，不把数值实验当成定理证明。

## 方法与实证

指出现有方法的具体失败条件，解释机制及设计选择；实验分别回答有效性、比较公平性、组件必要性、范围和成本。训练预算、调参预算、模型/数据规模需清楚，不默认要求所有方法都做同一套实验。未做实验作为待验证项，不写成已证实结论。

## 系统

定义工作负载、软硬件环境、系统边界、端到端指标和资源瓶颈。算法复杂度与实际吞吐是不同证据。报告测量条件和影响部署的限制，不以kernel microbenchmark推断整体系统收益。

## 分析与数据研究

区分描述性观察、相关性、机制解释与因果结论。任务、样本选择、构念和指标需可解释；原有假说应允许反证。风格档案不能替代领域专门的评估协议。

## 类型与 venue

以上类型是写作需求维度，不是某个会议专属风格。使用venue档案时优先比较同类型论文；样本分布不均衡需在判断中注明。
