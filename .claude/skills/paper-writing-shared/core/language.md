# 中文材料到英文稿／英文润色

中文输入先识别主语、技术对象、结果条件及主张边界，按英文论证组织段落，避免逐句保留重复背景。中文“证明”可能指理论证明或实验支持，须依材料区分 `prove` 与 `show`。

明确已有事实与作者意图；中文中省略的实验条件、统计口径、定理假设不能凭经验补齐。缩写首现展开，并维护同一术语与符号。保持公式、引用键、LaTeX命令及label不变。

优先使用具体动词和可判读的名词，移除无证据的“首次、显著、全面、普适”。用 `significant` 描述统计显著性时必须有检验依据；若只是改善幅度，使用实际数字或边界明确的措辞。

论文章节默认英文，修改说明和档案默认中文。作者要求中文正文时照办，但投稿模板的引擎/字体兼容另行检查，不能为中文显示静默改变官方排版。
