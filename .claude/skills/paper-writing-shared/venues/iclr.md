# ICLR：待全文验证的 venue 档案

核验日期2026-10-11。2024、2025各25篇主会正式论文已锁定，全部匹配[官方论文集](https://proceedings.iclr.cc/)、取得并逐页解析；**完整语义写作风格审阅1/50**。官方主PDF可能不包含所引用的附录，必须另查Supplementary；取得主文件不能计已完成全文及附录审阅。

## 模板与规则版本

[2027官方作者指南](https://iclr.cc/Conferences/2027/AuthorGuidelines)指定媒体站的 `iclr-2027-style-files.zip`，以此包为当前规范入口，保留原 `.sty`、`.bst` 与依赖。投稿正文9页、双匿名；终稿正文10页，使用 `\iclrfinalcopy`。参考文献及其后的附录不限页，鼓励同PDF合并；审稿人不必阅读附录。必需独立AI use statement不计正文页数，披露依[2027 AI政策](https://iclr.cc/Conferences/2027/AIPolicyForAuthors)及实际任务填写；Ethics与Reproducibility声明为建议，并非所有稿件强制伦理章节。旧 `AuthorGuide` 路径未成功不能作为规范缺失的最终结论。

## 十维暂定编辑规则

以下是编辑建议，不是语料观察；尚无完整已审支持样本和反例，不构造与其他会议的风格差异。

| 维度 | 可执行动作及当前边界 |
|---|---|
| 读者与目标 | 说明研究问题、已有解释/能力的缺口、方法或分析贡献；不将整个venue限定为某类神经网络或优化器。 |
| 标题与摘要 | 用实际对象、机制或发现组织，写清证据范围；是否采用缩写/冒号由稿件需要决定。 |
| 引言与贡献 | 贡献逐项对应定义、理论、实验或诊断结果，避免把评测规模等同研究意义。 |
| 相关工作 | 围绕直接近邻的假设、方法与结论比较，允许整合背景或独立节；位置尚无语料结论。 |
| 方法、算法、理论 | 明确符号、构造动机、操作与条件；提供与主结论对应的证明或证据指针。 |
| 实验与结果 | 比较条件与评价问题清楚，保留复现信息和失败边界；不用理论稿空缺的实验制造内容。 |
| 讨论、局限与结论 | 分清机制假说与已验证解释，未来泛化不能改为当前结论。 |
| 段落与措辞 | 因果、对照、限制和解释关系明确；不将发表稿的夸大词当官方偏好。 |
| 正文与补充 | 让正文能够独立理解主张；附录对应正文结果与设置。当前届次具体限页仍待核验。 |
| 可执行检查 | 起草主张—证据—边界表；润色保护符号、数学条件、数字、引用键与自定义命令。 |

## 一篇正文与官方补充材料的先导证据

`iclr-2024-710a9140`，[Adaptive Regret for Bandits Made Possible: Two Queries Suffice](https://proceedings.iclr.cc/paper_files/paper/2024/hash/6920c76183516fb8efff75416393a577-Abstract-Conference.html)：正式主稿11页及官方补充完整20页中的附录A–E已读；作者公开v1附录先读后与取得的官方附录逐页文本去空白比对一致。以下是**单篇先导观察，venue置信度低**，不是50篇规律；未重新验证证明正确性。

| 维度 | 支持位置与观察 | 执行动作与边界 |
|---|---|---|
| 读者 | §1先解释在线决策与变化环境 | 先定义问题价值，不假设所有读者熟悉子领域 |
| 标题/摘要 | p1以查询数和理论保证组织 | 数字可以是理论参数，不必是性能增幅 |
| 引言 | §1.1区分查询与计算开销，Table1对照保证 | 贡献对应准确资源口径，不将少查询改成少计算 |
| 相关工作 | §1.2按三类问题比较 | 独立大节不是必需；遵守目标届次政策 |
| 方法/理论 | §2假设，§3算法、定理与三步证明路线 | 条件和证明接口保留在主文 |
| 实验 | §5合成变化、组件对照、下游选择 | 分开机制验证与应用证据，不把一个例子外推全域 |
| 局限 | §6列对数因子、查询和动态遗憾问题 | 局限可与结论组织；不凭此删除官方必需栏目 |
| 措辞 | §1.1限定反馈模型，§6保留对数因子 | 理论最优须说明参数与忽略项 |
| 补充 | 正式主文件没有正文引用的附录 | 获取并核对独立Supplementary，不能按主PDF末页判断完整 |
| 改写 | §5.1仍运行多基学习器 | 保留资源和设置的差别；附录与正文不一致单独提示 |

官方完整附录A给算法、B/C给证明、D给BCO替代方案、E给扩大的合成实验。主文BCO三查询与附录两查询替代方案、结论中继续提出减少查询问题之间存在表述张力；应对作者提出核对项，不将接受稿的这种不一致模仿成风格。上述先导未用于验证留出规则。
