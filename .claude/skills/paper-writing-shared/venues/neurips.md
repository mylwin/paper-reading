## 官方要求

2026主会投稿匿名正文9页，终稿正文10页；参考文献、附录及必需checklist不计正文限制。单PDF按正文、参考文献、附录、checklist组织，使用年度官方样式。checklist逐项根据实际研究填写，不能默认全部Yes；影响与潜在后果需真实交代，不强制每稿增加独立Broader Impacts章节。[主会手册V2026.3](https://neurips.cc/Conferences/2026/MainTrackHandbook)

## 十维编辑建议

以下是通用编辑建议，不能称为50篇语料规律。下节为一篇先导提供支持、反例和适用边界；没有数据支撑的跨venue偏好仍待调查。

| 维度 | 目前可执行的通用动作 |
|---|---|
| 读者与目标 | 说明贡献解决的问题、与直接近邻的差异和证据类型；按理论、实证、系统等稿件类型调整细节。 |
| 标题与摘要 | 交代对象、方法/结果与适用范围，数字只来自真实材料，不要求所有摘要用性能提升收尾。 |
| 引言与贡献 | 将动机、缺口、贡献和后文证据关联，不以新颖形容词替代创新内容。 |
| 相关工作 | 按本文主张需要的对比组织；位置由论证和篇幅决定，尚无独立节比例结论。 |
| 方法与理论 | 先定义输入、输出与假设，再解释关键构造；定理条件和证明依赖保持原意。 |
| 实验与证据 | 每项比较对应贡献，保留协议、资源条件和不确定性；理论稿不强制经验实验。 |
| 讨论与局限 | 交代改变主张适用性的限制，将推断和已验证事实分开。 |
| 段落与措辞 | 给每段清楚论证动作；强措辞限定范围，避免从个别发表稿学到无证据的宣传语。 |
| 正文与附录 | 正文保留关键机制、条件及决定性证据；详细设置与推导附录回链；checklist位于末尾。 |
| 改写与检查 | 对照事实、数值、符号、引用和官方版式；压缩删冗余，不修改字号、边距或行距。 |

## 原创示例与验收缺口

输入为只在评测任务验证的改进时，可写 `The method improves the measured performance on the evaluated tasks. Its behavior outside these settings remains untested.` 这是范围表达示例，不是从50篇提取的典型句法。

40篇归纳与10篇留出均待语义审阅；每条语料规则需补支持论文位置、反例、适用类型、年份与置信度，再开展冻结规则后的独立检查。当前不能声称NeurIPS区别于ICML/ICLR的写作特征已经验证。

## Causal LLM Routing跨年度修订

[2025逐篇审阅](../../../../07-research/2026-10-10-顶会顶刊写作风格调研_证据/corpus/neurips/semantic-reviews/neurips-2025-aac4a9fe.json)覆盖正式PDF全部26页：正文1–10、参考文献10–12、A–D13–19及checklist20–26。所有科学证明与新增结果已读；checklist承诺的代码未在公开论文集找到，不声称已复现实验。8页关键公式、表格及协议直接视觉核对。

- **N-P1/N-P4修订（观察）**：本稿没有独立Related Work，文献定位融在Introduction、方法与基线；与2024独立节构成反例。两稿摘要都没有提升数字，重复次数分别10与30，统计呈现也不同。动作是按真实论证安排，不能硬套节名、数字摘要或30次运行。条件为这两篇理论＋实证先导，不是全会出现频率。
- **N-P2/N-P3修订（观察＋建议）**：p4的SUTVA、ignorability、support，以及p6–7的affine utility/准确endpoint条件必须保留。p8使用完整反馈基准模拟单模型历史记录，不能写成生产部署。p17表中kNN有多项胜于RM变体，p9的Baseline也非所有设置最差；总体改善不等于所有模型、预算或指标改善。
- **N-P6：方法、证明、实现需对应（编辑建议）**：p6公式/图、p15表示能力论证与p19实现描述有加法/拼接及端点加权对应需确认；p14区间数量与切换点数量的表述需核查。提出具体作者查询，不静默改公式或据此宣布整个定理无效。单篇对应问题高置信，未完成独立正确性证明。
- **N-P7：资源与指标的比较域须显式（编辑建议）**：p19延迟使用A100、大batch与预计算embedding，不能改写为已验证单请求在线延迟；p18 AUC需明确共同成本积分范围，训练得到的Full-Feedback比较器不自动成为数学oracle上界。
- **N-P5补充（观察＋官方版本区分）**：2024稿15项checklist，2025稿16项含LLM usage。样本回答是作者声明，不是技能默认答案；新稿加载目标届次的当前官方模板与政策，不复制旧稿的Yes/NA。

上述审计问题支持“先核对证据、再改措辞”的动作，不把原文错误包装成NeurIPS风格；跨年度观察仍不足以分离年份、题材、作者与稿件类型效应。
