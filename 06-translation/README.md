# 论文翻译结果

`06-translation/` 用于保存论文的翻译结果。翻译资料与原始 PDF、解析 Markdown 和阅读笔记相互独立。

每篇论文使用一个与论文标题一致的文件夹，翻译文件按形式命名：

```text
06-translation/
└── <论文标题>/
    ├── 双栏对比.<扩展名>
    ├── 单独翻译.<扩展名>
    └── <其他翻译形式>.<扩展名>
```

当前论文目录已预留；请将实际翻译文件放入对应目录，不要放在本目录根部。

- 每篇论文的目录名必须与 `01-raw/`、`02-markdown/` 和其他论文资料目录中的论文标题一致。
- 可同时保存双栏对比、单独翻译等不同形式，文件名应体现翻译形式。
- 翻译结果不应覆盖或修改 `01-raw/` 中的原始 PDF 和 `02-markdown/` 中的解析结果。
