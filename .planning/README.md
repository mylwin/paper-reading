# `.planning/` 任务规划档案

本目录统一保存项目任务的规划与过程记录，不在项目根目录散落
`task_plan.md`、`findings.md` 或 `progress.md`。

## 目录约定

每个任务使用一个稳定、简短的任务标识：

```text
.planning/
└── <任务标识>/
    ├── task_plan.md
    ├── findings.md
    └── progress.md
```

任务标识建议使用 `YYYY-MM-DD-简短主题`。不同任务不得共用同一组规划文件；
任务结束后可以保留档案供追溯，但论文资料目录和项目根目录不得放置这些文件。
